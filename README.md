## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Direct3D** — Efficiently processes and renders high-quality three-dimensional graphics.
- **DirectInput** — Handles data from keyboards, mice, and various controllers, enhancing gameplay interaction.
- **DirectSound** — Provides enhanced audio playback and recording capabilities.
- **DirectShow** — Plays sound and video with network transparency, ensuring smooth multimedia experiences.
- **DirectSetup** — Simplifies installation of DirectX components for a hassle-free setup.

### Advanced Features:
- **Shader Model 4.0** — Increases the capabilities of graphics rendering, allowing for more detailed textures and effects.
- **Geometry Shader** — Enables real-time creation of geometric shapes, enhancing the dynamic visual aspects of games.
- **DirectCompute** — Leverages multi-core processors for better performance in processing threads.
